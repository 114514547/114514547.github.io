这是本系列的最后一章。前面六章讲了每个目录的作用和用法，这一章按"从简到难"的顺序，告诉你 fork 模板之后具体该改什么、怎么改。

## 第一步：改站点基本信息（5 分钟）

打开 `_config.yml`，改这几个字段：

```yaml
title: "你的网站标题"
url: "https://你的用户名.github.io"
repository: "你的用户名/你的用户名.github.io"

author:
  avatar: "profile.png"      # 头像图片放到 images/ 目录
  name: "你的名字"
  bio: "一句话介绍自己"
  location: "你的城市"
  employer: "你的学校/单位"
  email: "your@email.com"
  github: "你的GitHub用户名"
```

改完之后，网站标题、侧边栏信息就变成你自己的了。

**踩坑提醒**：`url` 一定要以 `https://` 开头，不要加末尾的斜杠。写错了会导致所有资源链接（CSS、图片）加载失败，网站一片空白但又没有报错信息。

## 第二步：换头像和封面（5 分钟）

1. 把头像图片命名为 `profile.png`（或你在 `_config.yml` 里写的文件名），放到 `images/` 目录
2. 刷新网站，侧边栏头像就变了

如果想给首页加一个大的 banner 图，编辑 `about.md`（`_pages/` 目录下），在 frontmatter 里加：

```yaml
header:
  overlay_image: "your-banner.jpg"
```

图片同样放 `images/` 目录。

## 第三步：改导航栏（2 分钟）

编辑 `_data/navigation.yml`，取消注释你想显示的链接：

```yaml
main:
  - title: "首页"
    url: /
  - title: "文章"
    url: /year-archive/
  - title: "项目"
    url: /portfolio/
  - title: "关于"
    url: /about/
  - title: "CV"          # 取消注释这三行
    url: /cv/
  - title: "归档"
    url: /archive-layout-with-content/
```

加一个链接只需要两行（title + url），删掉也只需要注释掉对应行。

## 第四步：写你的第一篇博客（10 分钟）

在 `_posts/` 目录新建一个文件，文件名必须带日期：

```bash
_posts/2026-05-23-hello-world.md
```

内容：

```yaml
---
title: "Hello World"
date: 2026-05-23T12:00:00.000Z
tags: ["随笔"]
---

这是我的第一篇博客！
```

就这么简单。推送到 GitHub 后等一两分钟，刷新你的网站就能看到。

**踩坑提醒**：
- 文件名的日期格式必须是 `YYYY-MM-DD`，月份和日期要补零
- frontmatter 里的 `date` 和文件名里的日期最好保持一致
- `---` 前后不能有空格或空行（第一组 `---` 之前也不行）

## 第五步：添加你的论文/演讲（15 分钟）

在 `_publications/` 目录新建文件：

```yaml
---
title: "你的论文标题"
collection: publications
category: manuscripts       # 或 conferences、books
permalink: /publication/2026-my-paper
date: 2026-05-01
venue: '期刊名称'
citation: '你的名字. (2026). "论文标题." <i>期刊</i>. 1(1).'
---

论文的简短描述。
```

`_talks/`、`_teaching/`、`_portfolio/` 同理，参考第三章的格式。

如果你有十几篇论文要批量导入，用 `markdown_generator/` 会快很多——准备一个 CSV 文件，跑一次脚本就全部生成了。

## 第六步：改简历页（15 分钟）

你的项目有两种简历方式：

**方式 A：Markdown 简历**（简单直接）

编辑 `_pages/cv.md`，把里面的示例内容替换成你自己的：

```markdown
Education
======
* Ph.D in 你的专业, 你的学校, 2025
* M.S. in 你的专业, 你的学校, 2022

Work experience
======
* 2023 - Present: 你的职位
  * 你的单位
  * 你的工作内容
```

论文、演讲、教学经历会自动从对应的集合里读取，不用在简历页重复写。

**方式 B：JSON 简历**（结构化）

编辑 `_data/cv.json`，按 JSON Resume 格式填写。配合 `_pages/cv-json.md` 渲染。适合想要更精细控制简历排版的场景。

## 第七步：换主题配色（1 分钟）

在 `_config.yml` 里改一个词：

```yaml
site_theme: "mint"  # 试试 air, sunrise, mint, dirt, contrast
```

六种主题随便试，不满意改回来就行。

## 第八步：自定义样式（进阶）

如果你想改主题配色之外的细节（字体、间距、组件样式），去 `_sass/` 目录：

| 要改什么 | 改哪个文件 |
|---|---|
| 全局字体和基础排版 | `_sass/layout/_base.scss` |
| 导航栏样式 | `_sass/layout/_masthead.scss` |
| 侧边栏宽度 | `_sass/layout/_sidebar.scss` |
| 文章页排版 | `_sass/layout/_page.scss` |
| 列表页卡片布局 | `_sass/layout/_archive.scss` |
| 颜色变量 | `_sass/theme/_default_light.scss` |

**建议**：先用浏览器的开发者工具（F12）定位到你想改的元素，记住它的 CSS 类名，再去 `_sass/` 里搜索这个类名，就能找到对应的文件和行号。

## 第九步：修改布局模板（进阶）

如果你想改页面的 HTML 结构（比如在导航栏加一个搜索框、在页脚加备案号），需要动 `_layouts/` 或 `_includes/`：

| 要改什么 | 改哪个文件 |
|---|---|
| 页脚自定义内容 | `_includes/footer/custom.html` |
| `<head>` 里加自定义 CSS/JS | `_includes/head/custom.html` |
| 文章页整体结构 | `_layouts/single.html` |
| 首页布局 | `_pages/about.md` |

**原则**：优先改 `_includes/` 里带 `custom` 后缀的文件，而不是直接改 `_layouts/`。`custom` 文件是专门留给你加自定义内容的，不会和模板更新冲突。

## 完整的新手改造清单

按顺序做完这些，你就有了一个属于自己的学术主页：

- [ ] 改 `_config.yml` 的 title、url、author 信息
- [ ] 替换 `images/profile.png` 为自己的头像
- [ ] 编辑 `_data/navigation.yml` 调整导航栏
- [ ] 写一篇博客发到 `_posts/`
- [ ] 添加至少一篇论文到 `_publications/`
- [ ] 修改 `_pages/cv.md` 的简历内容
- [ ] 选一个喜欢的主题色
- [ ] （可选）调整 `_sass/` 里的样式
- [ ] （可选）自定义页脚或 `<head>` 内容

做完这些，push 到 GitHub，等 Actions 跑完，你的学术主页就上线了。
