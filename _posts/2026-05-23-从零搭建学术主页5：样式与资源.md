## 5.1 `_sass/` — 主题皮肤怎么改

`_sass/` 目录下是 SCSS（Sass）样式文件。你的项目结构如下：

```
_sass/
├── _syntax.scss         # 代码高亮样式
├── _themes.scss         # 六种预设主题的颜色定义
├── include/             # 各组件样式
│   ├── _mixins.scss
│   └── _utilities.scss
├── layout/              # 布局样式
│   ├── _base.scss       # 基础排版（字体、行高、间距）
│   ├── _masthead.scss   # 顶部导航栏
│   ├── _sidebar.scss    # 侧边栏
│   ├── _page.scss       # 文章页
│   ├── _archive.scss    # 归档列表页
│   ├── _footer.scss     # 页脚
│   ├── _buttons.scss    # 按钮
│   ├── _forms.scss      # 表单
│   ├── _tables.scss     # 表格
│   ├── _navigation.scss # 分页导航
│   ├── _notices.scss    # 提示框
│   ├── _json_cv.scss    # JSON 简历页样式
│   └── _reset.scss      # CSS Reset
├── theme/               # 主题色变量（每个主题一个 _light 和 _dark 文件）
│   ├── _default_light.scss
│   ├── _default_dark.scss
│   ├── _air_light.scss
│   ├── _air_dark.scss
│   ├── _sunrise_light.scss
│   ├── _sunrise_dark.scss
│   ├── _mint_light.scss
│   ├── _mint_dark.scss
│   ├── _dirt_light.scss
│   ├── _dirt_dark.scss
│   ├── _contrast_light.scss
│   └── _contrast_dark.scss
└── vendor/              # 第三方库
```

### 换主题最快的方式

在 `_config.yml` 里改一行：

```yaml
site_theme: "default"  # 改成 air, sunrise, mint, dirt, contrast 之一
```

六种预设主题分别是：
- **default** — 经典蓝
- **air** — 清新浅色
- **sunrise** — 暖橙
- **mint** — 薄荷绿
- **dirt** — 大地色
- **contrast** — 高对比度

每个主题都有 light（浅色）和 dark（深色）两套方案，跟随系统的深色模式自动切换。

### 换字体

你的项目已经自定义了字体。在 `_themes.scss` 里可以看到：

```scss
@font-face {
  font-family: "FZRuiHei";
  src: url("../fonts/FZRuiZHJW.TTF") format("truetype");
}

$sans-serif: "FZRuiHei", -apple-system, "San Francisco", "Roboto", ...;
$monospace: "JetBrains Mono", Monaco, Consolas, ...;
```

想换字体？两种方式：
1. **换系统字体**：改 `$sans-serif` 或 `$monospace` 变量
2. **用自定义字体**：把字体文件放到 `assets/fonts/`（或 `fonts/`），在 `_themes.scss` 里写 `@font-face`，然后引用

### 改某个组件的样式

比如你觉得顶部导航栏太高了，找到 `layout/_masthead.scss` 改对应的属性就行。每个文件对应一个组件，命名很直观：

| 文件 | 改什么 |
|---|---|
| `_base.scss` | 全局字体大小、行高、链接颜色 |
| `_masthead.scss` | 导航栏高度、背景色 |
| `_page.scss` | 文章页的标题、正文排版 |
| `_sidebar.scss` | 侧边栏宽度和样式 |
| `_archive.scss` | 列表页的卡片布局 |
| `_footer.scss` | 页脚 |

### 自定义颜色变量

`theme/` 下的文件定义了每个主题的颜色变量。比如 `_default_light.scss` 里会有一堆 `$primary-color`、`$background-color` 之类的变量。直接改这些值就能微调配色。

## 5.2 `assets/` — 图片、字体、自定义 CSS

`assets/` 目录存放网站的静态资源：

```
assets/
├── css/       # 编译后的 CSS（一般不用手动改）
├── fonts/     # 字体文件
├── js/        # JavaScript 文件
└── webfonts/  # Font Awesome 等 web 字体
```

### 图片放哪里？

很多人会纠结图片放哪个目录。其实有两个选择：

| 目录 | 用途 |
|---|---|
| `images/` | 博客文章和页面引用的图片（推荐） |
| `assets/` 下的子目录 | 主题相关的图片（logo、默认封面等） |

frontmatter 里写 `teaser: "cover.jpg"` 会自动去 `images/` 目录找。所以**图片统一放 `images/` 最省心**。

### 添加自定义 CSS/JS

不推荐直接改 `_sass/` 里的文件（虽然你的项目是 fork 可以改）。更稳妥的方式是：

1. 在 `assets/css/` 下新建一个 `custom.css`
2. 在 `_includes/head/custom.html` 里加一行引用：

```html
<link rel="stylesheet" href="{{ '/assets/css/custom.css' | relative_url }}">
```

这样你的自定义样式会覆盖主题默认样式，而且不怕以后改 `_sass/` 时搞混。

同理，自定义 JS 放 `assets/js/`，在 `_includes/head/custom.html` 或 `_includes/footer/custom.html` 里引入。

## 字体文件在哪？

你的项目根目录有一个 `fonts/` 文件夹（和 `_sass/` 同级），里面放了自定义字体文件。`_themes.scss` 里的 `@font-face` 引用的是 `../fonts/` 路径，也就是相对于 `_sass/` 向上一级找到 `fonts/`。

如果你想把字体也统一管理，可以移到 `assets/fonts/`，但记得同步改 `_themes.scss` 里的路径。

## 改样式的一般流程

> 1. 确定要改什么（导航栏？文章字体？按钮颜色？）
> 2. 找到对应的 SCSS 文件（命名很直观）
> 3. 改变量或直接改属性
> 4. 本地 `jekyll serve` 看效果
> 5. 满意后提交
