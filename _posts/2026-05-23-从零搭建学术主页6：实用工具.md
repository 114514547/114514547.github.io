前面五章把网站的结构、内容、样式都讲完了。这一章讲两个实用工具：批量生成论文页面的 Python 脚本，以及 VS Code 里可视化编辑 Front Matter 的方法。

## 6.1 `markdown_generator/` — 批量生成论文页面

如果你只有三四篇论文，手动建文件就行。但如果你有二三十篇，一个个写 frontmatter 就太痛苦了。`markdown_generator/` 就是解决这个问题的。

### 工作原理

```
CSV/TSV 数据表  →  Python 脚本  →  _publications/ 下的 .md 文件
```

你只需要维护一个表格（CSV 或 TSV 格式），脚本会自动批量生成论文页面。

### 数据格式

`publications.csv` 的表头：

```
pub_date, title, venue, excerpt, citation, url_slug, paper_url, slides_url, category
```

每一列的含义：

| 列名 | 说明 | 必填？ |
|---|---|---|
| `pub_date` | 发表日期，格式 `YYYY-MM-DD` | 是 |
| `title` | 论文标题 | 是 |
| `venue` | 发表刊物/会议 | 是 |
| `excerpt` | 简短描述 | 否 |
| `citation` | 引用格式 | 是 |
| `url_slug` | URL 中的标识符（生成文件名用） | 是 |
| `paper_url` | 论文 PDF 链接 | 否 |
| `slides_url` | 幻灯片链接 | 否 |
| `category` | 分类：manuscripts / conferences / books | 是 |

### 使用方法

```bash
cd markdown_generator
python publications.py publications.csv
```

脚本会在 `../_publications/` 目录下生成对应的 `.md` 文件。每行数据生成一个文件，文件名格式为 `YYYY-MM-DD-url_slug.md`。

### 支持的工具

`markdown_generator/` 里有多种工具可选：

| 文件 | 用途 |
|---|---|
| `publications.py` | 从 CSV/TSV 生成论文页面 |
| `talks.py` | 从 TSV 生成演讲页面 |
| `pubsFromBib.py` | 从 BibTeX 文件生成论文页面 |
| `publications.ipynb` | Jupyter Notebook 版的论文生成器 |
| `talks.ipynb` | Jupyter Notebook 版的演讲生成器 |
| `PubsFromBib.ipynb` | 从 BibTeX 导入的 Notebook |
| `OrcidToBib.ipynb` | 从 ORCID 导出 BibTeX 的 Notebook |

### 从 BibTeX 导入

如果你用 Zotero、Mendeley 等文献管理工具，可以导出 BibTeX 文件，然后用 `pubsFromBib.py` 或 `PubsFromBib.ipynb` 转换成 `.md` 文件。这样连 citation 字段都能自动生成。

流程：

```
Zotero → 导出 .bib 文件 → markdown_generator/ → 自动生成 _publications/*.md
```

### 注意事项

- 脚本生成的文件会**覆盖** `_publications/` 下同名文件，用之前先确认不会丢失手写的修改
- `url_slug` 要用英文和连字符，不要用空格或中文（它会成为 URL 的一部分）
- 日期格式必须是 `YYYY-MM-DD`，少一位或多一位都会报错

## 6.2 Front Matter —— VS Code 里可视化编辑

你的项目里有 `.frontmatter/` 目录和 `frontmatter.json` 配置文件，说明已经配置好了 [Front Matter](https://frontmatter.codes/) VS Code 扩展。

### 什么是 Front Matter 扩展？

Front Matter 是一个 VS Code 插件，让你不用手写 YAML frontmatter，而是通过图形界面来编辑。它会：

- 显示一个侧边面板，列出你所有的文章/论文/演讲
- 提供表单式的编辑界面（标题、日期、标签、分类都有输入框）
- 预览封面图
- 管理草稿状态

### 安装和启用

1. 在 VS Code 扩展商店搜索 "Front Matter" 并安装
2. 打开项目根目录，它会自动检测到 `frontmatter.json` 配置文件
3. 左侧边栏会出现 Front Matter 图标，点开就能看到内容管理面板

### 配置文件

`frontmatter.json` 定义了内容类型和字段映射。它告诉 Front Matter 扩展：
- `_posts/` 是博客文章，有哪些字段
- `_publications/` 是论文，有哪些字段
- 每种内容类型的 frontmatter 字段是文本框还是日期选择器还是下拉菜单

一般不需要手动改这个文件，用默认配置就够。

### 适合什么场景

- **批量修改 frontmatter**：比如要把所有文章的分类从 `blog` 改成 `teaching`，在面板里批量操作比手动改文件快
- **不熟悉 YAML 语法**：表单界面不用关心缩进和引号
- **管理大量内容**：面板会显示所有文章的列表，可以按日期、分类筛选

## 小结

这一章讲了两个效率工具：

| 工具 | 场景 |
|---|---|
| `markdown_generator/` | 有大量论文/演讲要导入时，从 CSV/BibTeX 批量生成 |
| Front Matter 扩展 | 在 VS Code 里用图形界面管理文章的 frontmatter |

如果你只有几篇论文，直接手动建文件更快。等量大了再考虑用工具。
