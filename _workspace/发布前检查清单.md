# 发布前检查清单

- [ ] 文件位于 `_drafts`，文件名以 `YYYY-MM-DD-` 开头
- [ ] `title` 与页面标题一致
- [ ] `description` 已填写为一句简短摘要
- [ ] `date` 是预期发布日期
- [ ] `tags` 与 `categories` 使用 YAML 列表
- [ ] 第一段可以作为文章列表摘要
- [ ] 图片位于 `images/posts/`，网页路径以 `/images/posts/` 开头
- [ ] 没有使用仅 Obsidian 可识别的 `![[图片]]` 或 `[[内部链接]]`
- [ ] 没有 API Key、Cookie、口令或私人路径
- [ ] 发布时只把目标文章移动到 `_posts`
- [ ] 确认不需要跨设备同步本地 `_drafts` 草稿
- [ ] Commit-and-sync 成功后在线核对文章页与首页列表
