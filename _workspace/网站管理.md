# 网站管理

> [!tip] 开始写作
> 按 `Ctrl + Alt + N` 新建技术文章草稿。草稿保存在 `_drafts`，不会进入公开仓库。

> [!success] 发布文章
> 完成检查后，将文章从 `_drafts` 移到 `_posts`，再按 `Ctrl + Alt + P` 提交并推送。

> [!info] 在线核对
> GitHub Pages 构建完成后，检查[线上主页](https://114514547.github.io/)与文章页面；需要查看提交记录时打开 [GitHub 仓库](https://github.com/114514547/114514547.github.io)。

## 基本发布路径

1. 按 `Ctrl + Alt + N`，填写标题并创建草稿。
2. 在 `_drafts` 中完成正文、摘要、标签和图片。
3. 对照[[发布前检查清单]]检查文章。
4. 将目标文章移动到 `_posts`。
5. 按 `Ctrl + Alt + P`，等待 Commit-and-sync 成功提示。
6. 在线核对首页、文章页、图片和移动端显示。

> [!warning] 使用边界
> `_drafts` 只保存在当前电脑。Obsidian Web Viewer 适合核对公开网页；登录 GitHub、修改仓库设置或处理敏感信息时，仍使用常规浏览器。
