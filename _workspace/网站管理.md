# 网站管理

> [!info] 基本发布路径
> 1. 运行 `QuickAdd: 新建技术文章草稿`。
> 2. 在 `_drafts` 中完成写作并检查属性。
> 3. 将文件移动到 `_posts`；文件名已经符合 Jekyll 的日期格式。
> 4. 按 `Ctrl + Alt + P`，执行 Git 的 Commit-and-sync。
> 5. 等待 GitHub Pages 构建，再打开线上主页核对。

`_drafts` 已被 Git 忽略：草稿只保存在本机，不会出现在公开仓库中。移动到 `_posts` 后才会进入 Git 发布流程。

## 使用边界

Obsidian 的 Web Viewer 适合查看公开网页和核对发布结果。登录 GitHub、修改仓库设置、处理密码或其他敏感操作时，仍使用常规浏览器。
